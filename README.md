# Fuel Daily · 每日健身营养

## 在线使用

### [打开每日摄入小工具 →](https://daily-fuel-nutrition.olazabalalameda897.chatgpt.site)

无需下载安装，点击上方链接即可打开。登录后可保存自己的饮食、饮水和宠物成长记录。

一个私人营养手账，支持按日期记录四餐、按食物重量换算热量和三大营养素、手动输入本次食用份量的营养数据、修改和删除记录、撤销删除、记录饮水，以及设置每日目标。

## 数据与目标

记录保存在 Sites D1，并按平台提供的用户 ID 隔离。浏览器存储不作为记录的来源。每日目标从选择的日期起生效，历史日期继续采用当时的目标。初始目标仅供演示，不是个人营养建议。

常用食物预设覆盖熟米饭、去皮烤鸡胸肉、去壳水煮蛋和干燕麦。参考 MyFoodData 展示的 USDA 数据，来源链接直接位于录入界面。实际营养会随品牌和烹饪方式变化，手动录入可使用食品包装上的数据。

## 本地开发

要求 Node.js >=22.13.0。使用现有锁文件安装依赖后运行项目的 dev 脚本。通过 /signin-with-chatgpt?return_to=/ 使用仅在本地启用的开发身份。生产身份由 Sites 提供。

数据库 schema 位于 db/schema.ts。先生成并检查迁移，再构建以生成本地 Wrangler 配置。按照 Sites 的数据库迁移流程应用 drizzle 目录中的迁移到本地预览，生产迁移随发布执行。禁止运行时创建表。

## 验证

类型检查、生产构建及本地浏览器流程检查。页面提供两个经过特性检测的 WebMCP 工具：读取当前日志和打开饮食表单；已安装浏览器不支持 document.modelContext，因此该可选接口无法在真实上下文中验证，不影响正常界面使用。

## 营养宠物「糯米」

新增可互动水豚伙伴，支持期待、开心、圆滚滚三种形象。饮食记录新增 foodKind 分类（nourishing、regular、treat），已有记录默认 regular。分类由用户确认，常用食物默认 nourishing。它是游戏分类，不用于推断个人健康。

宠物状态从真实保存的记录计算：近七日事件按日期和创建时间顺序影响活力和圆润度，累计记录影响等级。营养餐活力 +8、圆润度 -12；日常餐圆润度 -2；甜饮或油炸餐活力 -12、圆润度 +24。圆润度限制在 0–100，活力限制在 20–100。每条记录增长 10 成长值，每 5 条记录升一级。修改、删除及撤销会重新计算，重复请求不重复累计。饮水与摸头有短暂互动反馈。

新迁移：drizzle/0001_bright_oracle.sql，只新增带常量默认值的食物分类列，未修改已有迁移。已在本地验证食物分类、宠物状态保存、修改和撤销、重复请求、非法分类、电脑与手机布局。

宠物资产：public/pets/nuomi-states.png（2172 × 724，三格透明精灵图）。使用内置 image_gen 生成，单次调用，未使用 CLI。提示词：同一只焦糖色幼年水豚，绿色双叶芽与橙色围巾；平静微笑、举爪开心、圆肚坐姿三个状态；柔和 3D 毛绒质感，三格水平排列，透明背景，统一脚底基线，无文字无界面。显示由 CSS 精灵图定位与变换完成，原图透明通道保留。

## 小狗与小猫伙伴

伙伴选择包含小水豚糯米、小狗豆包、小猫布丁。选择保存于按用户隔离的 pet_profiles 表，通过 drizzle/0002_clean_zodiak.sql 创建。切换伙伴共用现有饮食与成长状态，不会复制记录或重置进度。标题、对白、摸头反馈和食物表单跟随伙伴变化。选择失败时保留原伙伴并显示提示，支持键盘左右键切换。

新增资产保存为 public/pets/doubao-states.png（2172 × 724）和 public/pets/pudding-states.png（2170 × 725），分别含平静、开心、圆滚滚三个水平状态。使用内置 image_gen，未用 CLI。初始提示词：与糯米水豚同系列的焦糖奶油色幼犬、橘白幼猫；绿色双叶芽和橙色围巾；平静期待、举爪开心、圆肚坐姿三种状态，柔和3D毛绒质感，三格等宽水平精灵图，全身完整，无文字或界面。

透明背景生成和一次背景提取未得到真实 alpha，因此最终选用浅蓝背景编辑：仅将假棋盘格替换为不透明纯浅蓝 #eaf3fd，保留角色、纹理、姿势、比例和三格布局，不添加文字或物体。最终图背景存在少量色阶差异，用页面显示时的轻微边缘遮罩融合到舞台，未修改图片像素。原图未被覆盖。
